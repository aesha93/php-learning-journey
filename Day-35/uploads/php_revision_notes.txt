
📘 PHP DAILY REVISION NOTES
------------------------------
📝 Description:
This file contains short and focused revision notes based on your completed learning topics in PHP so far. Use it daily to refresh concepts and remember syntax efficiently. These notes cover Indexed Arrays, Associative Arrays, and Functions (beginner to intermediate), which form the foundation of most PHP projects.

✅ Topics Covered:
1. Indexed Arrays
2. Associative Arrays
3. Functions

🔸 Indexed Arrays
- Definition: Array with numeric keys  
  $fruits = ["Apple", "Banana", "Mango"];
  echo $fruits[0]; // Apple

- Loop Example:
  foreach ($fruits as $fruit) {
      echo $fruit;
  }

🔸 Associative Arrays
- Definition: Key-value pairs  
  $expenses = ['Rent' => 10000, 'Food' => 3000];
  echo $expenses['Food']; // 3000

- Loop Example:
  foreach ($expenses as $key => $value) {
      echo "$key = $value";
  }

🔸 Functions Basics
- Declaration & Call:
  function greet() {
      return "Hello!";
  }
  echo greet();

- Function with Parameters:
  function greetName($name) {
      return "Hello, $name!";
  }

- Default Parameters:
  function greetTime($name = "Guest") {
      return "Good Day, $name!";
  }

- Conditional Logic:
  function customGreeting($name, $time = "Day") {
      if ($time == "Night") return "Good Night, $name!";
      elseif ($time == "Evening") return "Good Evening, $name!";
      return "Good Morning, $name!";
  }

- Return Total from Associative Array:
  function getTotalExpense($arr) {
      $sum = 0;
      foreach ($arr as $v) $sum += $v;
      return $sum;
  }

- Function with Reference:
  function safeAdd(&$arr, $key, $value) {
      if (!array_key_exists($key, $arr)) {
          $arr[$key] = $value;
      } else {
          echo "Key already exists";
      }
  }
